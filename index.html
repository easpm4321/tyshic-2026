關於我們

大家好，我們是桃高資訊社！
我們的社團專注於 Python 程式設計 與 網路爬蟲應用，專為對程式設計、資料擷取與邏輯思維有興趣的同學量身打造！無論你是完全沒有經驗的初學者，還是想提升實作能力的新手，我們都會手把手帶領大家從零開始。 ～(∠・ω< )⌒☆

扎實豐富的課程脈絡

從最基礎的 Python 環境設定、變數與邏輯控制，到迴圈、資料結構（list/dict）與函式模組；接著更會帶大家跨入實用領域，學習網路基礎、HTML 結構，並運用 Requests 與 BeautifulSoup 進行網頁資料擷取與 CSV/JSON 儲存。最後還有爬蟲專題實作與期末成果展示，讓你完整體驗從無到有寫出專案的成就感！
